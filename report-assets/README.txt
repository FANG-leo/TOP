Generated report assets
=======================

This directory was generated by `scripts/generate_report_assets.py`.

Main outputs:
- `version_evolution.csv` / `.tex` / `.png`: version-by-version FOM evolution for the single-run chain.
- `all_runs_summary.csv`: flat summary of every parsed run.
- `v12_perf_matrix.csv` / `.tex`: matrix table for the selected version.
- `v12_heatmap.png`: MPI/OpenMP heatmap for the selected version.
- `v12_mpi_scaling.png`: MPI scaling plot using OMP=1 runs.
- `v12_openmp_scaling.png`: OpenMP scaling plot using np=1 runs.
- `counter_comparison.csv` / `.tex`: perf stat comparison for v9-np1-omp8, v12-np2-omp1.
- `*_hotspots.csv` / `.tex` / `.png`: hotspot tables and plots for selected runs.
